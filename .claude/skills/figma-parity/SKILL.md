# Сверка кита с макетом Anthropic

Кит `instrument` подтягивается к макету Anthropic Community UI. Макет — эталон
качества, стиля и источник недостающих компонентов; правила кита при
необходимости пересматриваются, но осознанно и по одному.

Работа идёт **группами компонентов**. Одна группа за проход: разбор, сверка,
решение о переносе, правка, гейты.

## Где что лежит

| Что | Где | Чем читать |
|---|---|---|
| Полный дамп «Copy as CSS» из Figma, все группы | `temp/components-dump.css` | `tools/cmd/figma` |
| Экспорты SVG по группам | `temp/*.svg` | `grep` по `<rect`, парсер путей |
| Собранные экраны | `temp/compositions/*.svg` | то же |

`temp/` в `.gitignore` — дамп и SVG в репозиторий не едут, читалка едет.

Дамп — 25 тысяч строк. **Не читайте его целиком, спрашивайте.**

```bash
go -C tools run ./cmd/figma -sum                      # опись значений по всему набору
go -C tools run ./cmd/figma -find "button|chip"       # узлы по имени
go -C tools run ./cmd/figma -at 827 -ctx 18 -full     # узел с соседями по дереву
go -C tools run ./cmd/figma -props font-size,padding  # таблица свойств
go -C tools run ./cmd/figma -list                     # все имена с повторами
```

Порядок узлов в дампе — обход дерева слоёв, поэтому группа лежит сплошным
куском: найдите её кадр через `-find`, дальше берите диапазон через `-at … -ctx`.

## Опорная ячейка

Макет соответствует **`scale 14` при обычной плотности** — умолчанию кита.

| | макет | кит |
|---|---|---|
| база интерфейса | 14 | `--text-sm: 14` |
| мелкие подписи | 11 · 12 | `--text-xs: 12.5` |
| чип, селект | 25 · 26 | `--control-h-sm: 26` |
| кнопка | 33 | `--control-h-md: 32` |
| радиус контрола | 8 | `--radius-control-md: 8` |

Числа макета кладите **в токены этой ячейки, никогда в пиксели**: остальные 14
сочетаний масштаба и плотности кит выведет сам. Отдельные компоненты берут
ступень выше базы намеренно — у главной кнопки подпись 16, и это её решение, а
не базовый кегль.

## Два источника, два искажения

Ни одному нельзя верить целиком.

**SVG** отдаёт отрисованное: точную геометрию, цвета, реальные радиусы. Но текст
в нём переведён в кривые — ни гарнитуры, ни кегля, ни трекинга, ни отступов, ни
имён состояний. Тени приходится собирать из примитивов `feOffset` /
`feGaussianBlur` / `feColorMatrix` (расплыв в CSS = удвоенная `stdDeviation`).

**Дамп** отдаёт объявленное: гарнитуру, начертание, интерлиньяж, трекинг,
`padding`, `gap`, готовый `box-shadow`, имена вариантов. Но у него два известных
перекоса, оба в сторону завышения:

1. **Пилюли.** Если объявленный `border-radius` достаёт до половины высоты,
   Figma при отрисовке подрезает его — реальная форма пилюля, а число смысла не
   несёт. `chip / preset`: объявлено 12, высота 19, отрисовано 9.5. Таких узлов
   в наборе 18.
2. **`leading-trim: both; text-edge: cap`.** У части текстовых узлов высота
   посчитана по прописной, а не по строке. `chip / preset` высотой 19 — это
   6 + 7 + 6, а не 6 + 13 + 6. В CSS такого поведения по умолчанию нет, и
   высоту оттуда нельзя переносить как есть.

Поэтому: **числа сверяйте по SVG, всё остальное берите из дампа.** На каждой
группе делайте перекрёстную проверку — она уже дважды ловила ошибку.

## Что уже выяснено про систему Anthropic

Не переоткрывайте. Подробности и накопленные по группам факты — в
[references/mockup-system.md](references/mockup-system.md), читайте его перед
разбором новой группы.

Коротко самое рабочее:

- **Акцент `#AA532E` — это ваш `clay --a-4`** с точностью до округления
  (`oklch(0.543 0.125 42.5)` против `oklch(0.560 0.130 45)`).
- **Чёрная прозрачность — контролы, белая — поля.** Кнопки и их состояния:
  чёрный 0.1–0.4. Все 24 узла `input` и `search`: белый 0.08 → 0.09. Ни одного
  исключения. Читается как «нажимаемое врезано в поверхность, заполняемое
  приподнято над ней».
- **Начертаний два**: 400 (239 раз) и 500 (111). 700 и 600 — единичные выбросы.
- **Трекинг — исключение**: стоит у 31 узла из 1446, почти везде `-0.5px`.
- **Мусор, который легко принять за дизайн**: пунктир `#9747FF` — граница
  компонента в Figma; узлы `Vector` с `rgba(255,255,255,0.6)` — заливка глифов,
  а не поверхность; `Auto layout` и `Inside auto layout` — служебные пометки.

## Правила переноса

Здесь сосредоточена вся цена ошибки: перенести лишнее так же плохо, как
пропустить нужное.

**Прежде чем назвать что-то дырой — прочтите таблицы маршрутизации.** У каждой
страницы компонента есть раздел «Когда использовать» со столбцом «Возьмите
другое». Кит часто уже отправляет случай в другое место, и это принятое решение,
а не упущение. Отменять его можно, но осознанно и с доказательством, что
существующий адрес случай не берёт. Проверьте заодно, не решён ли вопрос иначе:
у сегментированного контрола наведение — полупрозрачный слой поверх заливки
выбранного, и три канала макета там сведены к одному без потерь.

**Относительное против абсолютного.** Если компонент лежит то на странице, то на
панели, то в модалке, его заливка обязана считаться от того, что под ним:
`--surface-recessed`, а не ступень рампы. Абсолютная ступень знает одну глубину
и на приподнятой панели даёт двойной провал — 0.087 вместо 0.033. На этом уже
ловились умолчание кнопки, тег и бейдж; при каждой новой заливке проверяйте
заново.

**Чего не переносить.** Градиенты, засечную гарнитуру, брендовые элементы
(`chip / plan` — бейдж подписки). И собственные несогласованности Anthropic:
у них вторичная кнопка на наведении светлеет, а иконочная темнеет — из одной и
той же точки в разные стороны. Единого правила там нет, и отмывать его через кит
не нужно.

**Комментарии — проектный журнал кита.** Под каждым решением лежит развёрнутое
«почему». Меняя значение, перепишите обоснование, которое защищало старое:
оставить запись «заливка, а не прозрачность, иначе тень висит вокруг дырки» под
кодом, где тени больше нет, — хуже самой правки. Пишите так же: что было, чем
ловилось, почему стало так.

## Гейты

Правка не считается сделанной, пока не прошла всё это.

```bash
go -C tools run ./cmd/dist        # собрать dist/, проверить баланс скобок
go -C tools run ./cmd/contrast    # контраст пар токенов, 6 тем × 4 акцента
go -C tools run ./cmd/targets     # цели нажатия, 15 сочетаний
go -C tools run ./cmd/proportion  # отношения размеров
go -C tools run ./cmd/docscheck   # документация против кита, в обе стороны
go -C site run ./cmd/site         # контракт страниц: разделы, спрайт, примеры
```

Что тянет за собой изменение — чек-лист в
[references/kit-gates.md](references/kit-gates.md). Читайте его, **прежде чем**
заводить класс, токен или компонент: сборка сайта падает на отсутствующем
символе спрайта и на нехватке обязательного раздела, `docscheck` — на классе без
страницы.

## Проверка глазами и руками

Панель предпросмотра открывается на документации:

```bash
# .claude/launch.json, конфигурация docs, порт 4322
```

Тема, акцент, масштаб и плотность живут атрибутами на корне, но переключатель
сайта их перезаписывает — ставьте атрибуты и снимайте скриншот в одном заходе,
либо кладите семантические токены прямо инлайном на свой контейнер.

**Поведение проверяйте скриптом, а не скриншотом.** Прогон через
`javascript_tool` — щёлкнуть, послать `keydown`, сравнить `aria-*` до и после —
ловит то, чего на картинке не видно. На чипе он поймал две настоящие ошибки:
стрелка переключала выбор в множественной группе, и полоса была горизонтальной
при вертикальной по умолчанию оси `listbox`. Скриншот показывал бы правильную
картинку в обоих случаях.

## Порядок прохода по группе

1. Найти диапазон узлов группы в дампе, выписать компоненты с числами.
2. Свериться с SVG той же группы; расхождения объяснить, а не замять.
3. Сопоставить с тем, что в ките есть, — включая таблицы маршрутизации.
4. Разделить находки: править · добавлять · **не брать** (с причиной).
5. Правки — токенами опорной ячейки, с переписанными комментариями.
6. Гейты. Затем проверка в браузере: вид скриншотом, поведение скриптом.
7. Дописать новые факты в `references/mockup-system.md`.

Отрицательный итог — полноценный результат. У группы Labels & Chips из четырёх
компонентов не взяли ничего, зато нашли ту же ошибку с абсолютной заливкой в
теге и бейдже. Об этом и надо докладывать: что взято, что отклонено и почему.
