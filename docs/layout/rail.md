Вертикальная навигация одними значками, прижатая к краю окна. Разделы опознают
**по форме глифа**, а не по слову, поэтому подписи в рельсе нет — она уходит в
подсказку и в доступное имя.

```html preview
<nav class="inst-rail" aria-label="Разделы">
  <a class="inst-rail-item" href="#рельс" aria-current="page" aria-label="Файлы">
    <svg class="inst-icon" aria-hidden="true"><use href="#i-list"/></svg>
  </a>
  <a class="inst-rail-item" href="#рельс" aria-label="Проекты">
    <svg class="inst-icon" aria-hidden="true"><use href="#i-grid"/></svg>
  </a>
  <a class="inst-rail-item" href="#рельс" aria-label="Прогоны">
    <svg class="inst-icon" aria-hidden="true"><use href="#i-refresh"/></svg>
    <span class="inst-badge inst-badge--count inst-rail-count">11</span>
  </a>
  <a class="inst-rail-item inst-rail-spacer" href="#рельс" aria-label="Параметры">
    <svg class="inst-icon" aria-hidden="true"><use href="#i-settings"/></svg>
  </a>
</nav>
```

## Использование

Рельс — это `<nav>` со своим именем и ряд ссылок внутри. Значок обязан нести
`aria-hidden`, а имя раздела — жить в `aria-label` самой ссылки.

```html
<nav class="inst-rail" aria-label="Разделы">
  <a class="inst-rail-item" href="/files" aria-current="page" aria-label="Файлы">
    <svg class="inst-icon" aria-hidden="true"><use href="#i-list"/></svg>
  </a>
</nav>
```

| Что | Обязательно | Почему |
|---|---|---|
| `aria-label` на каждом пункте | да | Кнопка без текста не имеет доступного имени. Без него рельс читается как ряд пустых кнопок |
| `aria-hidden` на значке | да | Иначе скринридер зачитает содержимое SVG поверх имени |
| `aria-current="page"` на текущем | да | Заливка сообщает выбор глазу, атрибут — всему остальному |
| Подсказка при наведении | нет, но желательно | Форма глифа опознаётся не всеми и не сразу |
| Переход по адресу — `<a>` | да | Раздел имеет адрес, и средний клик обязан работать |

## Когда использовать

| Используйте | Возьмите другое |
|---|---|
| Разделов немного, они постоянны, и каждому есть однозначный значок | **Пунктов больше восьми или значка нет** — [боковая навигация](./shell.md) с подписями: рельс из десяти похожих глифов не читается |
| Место дороже подписи: окно инструмента, где колонка занята содержимым | **Выбор одного из равных на виду** — [сегментированный контрол](../components/actions/segmented.md) |
| У раздела бывает счётчик непрочитанного или изменённого | **Действие, а не переход** — [иконочная кнопка](../components/actions/button.md) |

## Устройство

| Часть | Что делает |
|---|---|
| `.inst-rail` | Колонка. Ширина не задана числом: она складывается из отступа и кнопки, поэтому едет за плотностью |
| `.inst-rail-item` | Кнопка `--control-h-lg`. **Крупнее `--tap-min` намеренно**: значок 24px в цели 24px заполнил бы её целиком |
| `.inst-rail-spacer` | Прижимает остаток к низу. Учётная запись и параметры стоят внизу, а не отбиты отступом |
| `.inst-rail-count` | Угол глифа снаружи. Изнутри счётчик закрыл бы форму, по которой раздел опознают |

Текущий раздел несёт **два носителя**: заливку и метку у края. Одной заливки
мало — на приглушённой поверхности рельса она едва отличается от наведения;
метка видна периферийным зрением и не спорит с глифом.

## Доступность

| | |
|---|---|
| Доступное имя | Только из `aria-label`. Значок — картинка, и текста в нём нет |
| Цель нажатия | `--control-h-lg`, то есть 38px при обычной плотности и 32 при плотной — выше нормы 24 в обеих |
| Текущий раздел | `aria-current="page"`, а не только цвет: цвет как единственный носитель кит запрещает |
| Контраст глифа | `--text-secondary` в покое, `--accent-text` у текущего — оба выше 4.5:1 в шести темах |
| Ориентир | `<nav>` с `aria-label`, иначе на странице два безымянных ориентира навигации |
