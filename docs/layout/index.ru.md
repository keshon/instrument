Восемь примитивов, и ни один из них не рисует — они только расставляют. Разница
между ними в **масштабе**: оболочка держит окно, сплит и контейнер держат экран,
стопка и кластер держат блоки внутри него.

| | что держит | сколько на документ |
|---|---|---|
| [Оболочка](./shell.md) | окно целиком, области с независимой прокруткой | одна |
| [Рельс](./rail.md) | узкая колонка разделов со значками | один, внутри оболочки |
| [Строка состояния](./statusbar.md) | показания внизу окна | одна |
| [Контейнер](./container.md) | ширину и боковые поля содержимого | сколько угодно |
| [Сплит](./split.md) | две колонки разной важности | сколько угодно |
| [Поток](./flow.md) | ритм: стопка, кластер, сетка | везде |
| [Шапка экрана](./page-header.md) | название экрана и его действия | одна на экран |
| [Секция](./section.md) | заголовок блока внутри экрана | сколько угодно |

Сравнение стоит здесь, а не на страницах: «возьмите другое» — это утверждение о
СОСЕДЯХ, и повторённое восемь раз оно расходится с ними по одной строке за
правку.

## Что выбрать

| Что нужно | Возьмите | Почему не соседа |
|---|---|---|
| Каркас всего приложения с независимо прокручиваемыми областями | [Оболочку](./shell.md) | Сплит переносится сам и не занимает всю высоту окна |
| Две части разной важности: список и его инспектор | [Сплит](./split.md) | У сетки все колонки одинаковые |
| Ограничить ширину содержимого и дать боковые поля | [Контейнер](./container.md) | Он задаёт только ширину; ритм — работа потока |
| Вертикальный ритм между блоками | `inst-stack` — [поток](./flow.md) | Контейнер про ширину, а не про просветы |
| Ряд, который переносится по ширине | `inst-cluster` — [поток](./flow.md) | У сплита есть порог переноса, у кластера нет |
| Карточки в адаптивную сетку | `inst-grid` — [поток](./flow.md) | У таблицы строки и заголовки колонок |
| Название экрана и 1–3 действия над ним | [Шапку экрана](./page-header.md) | Секция тише и не претендует на `<h1>` |
| Заголовок блока внутри экрана | [Секцию](./section.md) | У панели есть рамка, фон и своя прокрутка |
| Разделы значками, когда место дороже подписи | [Рельс](./rail.md) | Из десяти похожих глифов рельс не читается — там нужны подписи |
| Постоянные показания окна: ветка, кодировка, счётчик ошибок | [Строку состояния](./statusbar.md) | Тулбар держит контролы и потому вдвое выше |

## Когда ни один не подходит

| Что нужно | Возьмите | Почему не отсюда |
|---|---|---|
| Область приложения с рамкой, шапкой и прокруткой | [панель](../components/display/panel.md) | Примитивы раскладки не рисуют |
| Инструменты над содержимым панели | [тулбар](../components/navigation/toolbar.md) | Он часть панели, а не раскладки экрана |
| Табличные данные | [таблицу](../components/display/table.md) | У сетки нет строк и заголовков колонок |
| Сообщение уровня экрана | [баннер](../components/feedback/banner.md) | Строку состояния читают краем глаза |
| Итог таблицы | `tfoot` | Он стоит под своими данными, а не внизу окна |
| Действие, а не переход | [иконочную кнопку](../components/actions/button.md) | Пункт рельса ведёт на адрес |

## Общее для всех восьми

**Примитив не рисует.** Ни рамки, ни фона, ни тени: как только раскладка
начинает красить, её нельзя вложить в то, что красит иначе. Рисуют панель и
карточка, и это их работа.

**Просвет называется намерением, а не числом.** `--gap-section` между
разделами, `--gap-row` внутри, `--gap-inline` в строке. Шкала `--space-*`
берётся напрямую только там, где роли нет и заводить её не на что, — и это
сторожит [гейт сборки](../about/audit.md).

**Компонент отвечает на ширину СВОЕЙ области, а не окна.** Поэтому в ките два
именованных `@container` — `app` и `content` — и ровно одна медиазапросная
точка на всю библиотеку, у оболочки.
