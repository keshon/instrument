Панель во всю высоту у края экрана. Тот же нативный `<dialog>`, что и у
[модалки](./dialog.md), — **другая раскладка, не другой компонент**.

```html preview
<dialog class="inst-dialog inst-sheet" id="dlg-params">
  <form method="dialog">
    <div class="inst-dialog-head">
      <span class="inst-dialog-title">Параметры прогона</span>
      <button class="inst-btn inst-btn--sm inst-btn--ghost inst-dialog-close" type="submit" aria-label="Закрыть">✕</button>
    </div>
    <div class="inst-dialog-body">
      <dl class="inst-kv">
        <dt>Модель</dt><dd>opus</dd>
        <dt>Агентов</dt><dd>7 из 12</dd>
        <dt>Токенов</dt><dd>184 320</dd>
        <dt>Начат</dt><dd>19:38:04</dd>
      </dl>
    </div>
    <div class="inst-dialog-foot inst-dialog-foot--end">
      <button class="inst-btn" type="submit">Закрыть</button>
    </div>
  </form>
</dialog>
```

> Открытие — **одна строка скрипта**: `document.getElementById('dlg-params').showModal()`.
> Подложка, ловушка фокуса, `Escape` и возврат фокуса на кнопку — от
> платформы, как у модалки.

`inst-sheet` — модификатор поверх `inst-dialog`, а не замена: класс базы
остаётся, части (`-head`, `-body`, `-foot`) те же.

## Когда использовать

| Используйте | Возьмите другое |
|---|---|
| Подробности объекта, которые смотрят, не теряя список из виду | **Вопрос, требующий ответа «да» или «нет»** — [модалка](./dialog.md): она короче и центрируется |
| Длинная форма, не помещающаяся в модалку по высоте | **Форма, ради которой уместно уйти на страницу** — обычный вид: шторка в 28rem шириной тесна для сложной [формы](../inputs/form.md) |
| Фильтры и параметры, которые правят и сразу видят результат | **Список действий над объектом** — [меню](./menu.md) в [поповере](./popover.md) |
| Второстепенный контекст сбоку от основного вида | **Постоянная панель, которую не закрывают** — колонка [оболочки](../../layout/shell.md): у шторки есть подложка, и фон под ней выключен |

## Сторона

```html
<!-- У конечного края (по умолчанию) -->
<dialog class="inst-dialog inst-sheet">…</dialog>

<!-- У начального края -->
<dialog class="inst-dialog inst-sheet inst-sheet--start">…</dialog>
```

| Класс | Край | Граница |
|---|---|---|
| `inst-sheet` | Конечный (справа в LTR) | Волосок по начальному краю |
| `inst-sheet--start` | Начальный (слева в LTR) | Волосок по конечному краю |

Стороны логические, а не физические: в RTL шторка зеркалится сама, править
ничего не нужно.

## Справочник

### Классы

| Класс | Работа |
|---|---|
| `inst-sheet` | Раскладка во всю высоту у конечного края. Только вместе с `inst-dialog` |
| `inst-sheet--start` | Тот же блок у начального края |

Все части — от [модалки](./dialog.md): `inst-dialog-head`,
`inst-dialog-title`, `inst-dialog-close`, `inst-dialog-body`,
`inst-dialog-foot`, `inst-dialog-foot--end`, `inst-dialog-foot-note`.

### Что меняет модификатор

| Свойство | Модалка | Шторка |
|---|---|---|
| ширина | `min(34rem, 100vw - var(--space-8))` | `min(28rem, 100vw)` |
| высота | `min(80dvh, 100dvh - var(--space-8))` | `100dvh` |
| поля | `margin: auto` — по центру | Прижата к краю |
| радиус | `--radius-lg` | `0` — блок примыкает к краю экрана |
| рамка | По периметру | Только со стороны содержимого |

На узком экране `min(28rem, 100vw)` даёт шторку во всю ширину — отдельного
мобильного варианта заводить не нужно.

### Обязательная разметка

| Что | Почему |
|---|---|
| `inst-dialog` вместе с `inst-sheet` | Поверхность, тень, подложка и раскладка частей приходят из базы |
| Нативный `<dialog>` | Модальность и `Escape` — от платформы |
| `showModal()` | `show()` открывает немодально: ни подложки, ни инертного фона |
| `<form method="dialog">` внутри | Закрытие кнопкой без скрипта |
| `aria-label` у крестика | Кнопка без текста иначе не имеет доступного имени |

### Токены

`--surface-overlay` · `--shadow-modal` · `--scrim` · `--border` ·
`--hairline` · `--pad-card` · `--space-5` · `--gap-inline` · `--text-md`

## Доступность

| | |
|---|---|
| Фокус | Ловушка фокуса и возврат на вызвавшую кнопку — от `showModal()` |
| Клавиатура | `Escape` закрывает. Кнопки внутри `<form method="dialog">` закрывают нажатием |
| Фон инертен | Подложка выключает фон для мыши и для скринридера. Если нужен доступ к фону, это не шторка, а колонка [оболочки](../../layout/shell.md) |
| Прокрутка фона | Останавливается тем же правилом `html:has(dialog[open])`, что и у модалки |
| Высота | `100dvh`, а не `100vh`: на мобильных панель браузера не срезает подвал с кнопками |
| Печать | Шторка на листе не печатается |
