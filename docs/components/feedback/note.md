Врезка **в поток**: поясняет то, рядом с чем стоит. Только полоса у ближнего
края и значок — ни заливки, ни рамки, ни места под кнопку.

```html preview
<div class="inst-note" data-tone="warn">Необратимо: восстановление из резервной копии занимает до суток.</div>
<div class="inst-note" data-tone="neutral">Лимит проверяется перед стартом каждого агента, а не по факту.</div>
```

## Сноска или баннер

Их путают чаще всего, и разница не в размере, а в **области действия**.

| | Сноска | [Баннер](./banner.md) |
|---|---|---|
| К чему относится | К соседнему абзацу, полю, блоку | Ко всему экрану |
| Где стоит | В потоке, там, где нужна | Наверху вида или области |
| Оформление | Полоса у края, углы прямые | Заливка, рамка, скруглённые углы |
| Действие | Нет места и не предполагается | `inst-banner-actions` |
| Заголовок | Нет | `inst-banner-title` |

Проверка в одну фразу: **если сообщение осмысленно вне того места, где стоит,
это баннер**. «Артефакты недоступны до 21:00» верно для всего экрана — баннер.
«Необратимо» верно только рядом с кнопкой удаления — сноска.

## Когда использовать

| Используйте | Возьмите другое |
|---|---|
| Оговорка к соседнему абзацу или полю | **Условие уровня страницы** — [баннер](./banner.md) |
| Предупреждение рядом с разрушительным действием | **Вопрос, требующий ответа** — [модалка](../overlays/dialog.md) |
| Пояснение внутри [панели](../display/panel.md) или тела модалки | **Подсказка, всплывающая по наведению** — [тултип](../overlays/tooltip.md) |
| Комментарий к тому, что пользователь сейчас читает | **Сбой, у которого должен быть выход** — [блок отказа](../../agent/failure.md): у сноски нет действия |

## Тон

```html preview
<div class="inst-note">Без тона: значка нет, полоса нейтральная.</div>
<div class="inst-note" data-tone="neutral">Информация. Синий в ките занят акцентом, поэтому роль info исполняет neutral.</div>
<div class="inst-note" data-tone="running">Идёт прямо сейчас.</div>
<div class="inst-note" data-tone="ok">Проверка пройдена.</div>
<div class="inst-note" data-tone="warn">Прогон завершится, но с замечаниями.</div>
<div class="inst-note" data-tone="error">Валидация путей не прошла.</div>
```

Тон несёт **иконку**, а не только цвет полосы. Раньше `warn` и `error`
отличались друг от друга исключительно цветом — прямое нарушение собственного
закона «цвет не может быть единственным носителем». Набор масок общий со
[баннером](./banner.md): одна форма значка на два компонента.

| Тон | Значок |
|---|---|
| без атрибута | Значка нет, полоса `--border-strong` |
| `data-tone="neutral"` | «i» в круге |
| `data-tone="running"` | «i» в круге |
| `data-tone="ok"` | Галка в круге |
| `data-tone="warn"` | Треугольник |
| `data-tone="error"` | Крест в круге |

## Справочник

### Классы

| Класс | Работа |
|---|---|
| `inst-note` | Всё. У сноски нет частей: заголовка и действий у неё не бывает по определению |

### Атрибуты

| Атрибут | Словарь |
|---|---|
| `data-tone` | `neutral` `running` `ok` `warn` `error`. Закрыт. Без атрибута значок не рисуется |

### Токены

`--size-marker` · `--size-icon` · `--tone-ink` · `--border-strong` ·
`--pad-panel` · `--space-3` · `--gap-inline` · `--text-sm` ·
`--text-secondary` · `--leading-ui`

Углы прямые намеренно: у сноски только одна граница — левая, — и скругление на
одной стороне выглядит как обрезанный блок.

Значок центрируется по **первой строке** текста: `calc((1lh - var(--size-icon))
/ 2)`. `1lh` — реальная высота строки, поэтому формула подстраивается под кегль
и плотность сама. Ручной сдвиг на `-1px`, который тут был раньше, задирал
значок на 2.1px вверх.

## Доступность

| | |
|---|---|
| Появление | Сноска, возникшая в ответ на действие, обязана попасть в `aria-live="polite"`. Кит роли не ставит: он не знает, появилась она сейчас или была изначально |
| Цвет не единственный носитель | Тон несёт значок **и** текст. Ради этого значок и появился |
| Контраст | Текст берёт `--text-secondary` — 4.5:1 в шести темах |
| Полоса не носитель смысла | Смысл несут значок и слова; полоса только группирует |
| Печать | Печатается: это часть содержимого, а не оформление |
| Режим принудительных цветов | Значок переводится на системный цвет текста и переживает сброс |
