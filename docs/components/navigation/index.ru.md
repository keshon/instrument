Шесть компонентов, и первый вопрос к любому: **это переход по адресу или выбор
значения?** Переход — навигация, вкладки, крошки, пейджер. Выбор — не отсюда:
это [сегментированный контрол](../actions/segmented.md) или
[селект](../inputs/select.md).

Сравнение стоит здесь, а не на страницах: «возьмите другое» — это утверждение о
СОСЕДЯХ, и повторённое шесть раз оно расходится с ними по одной строке за
правку.

## Что выбрать

| Что нужно | Возьмите | Почему не соседа |
|---|---|---|
| Постоянный список разделов приложения | [Навигацию](./nav.md) в колонке [оболочки](../../layout/shell.md) | У вкладок другая работа и другое место на экране |
| Несколько видов одних и тех же данных, у каждого свой адрес | [Вкладки](./tabs.md) | Навигация ведёт между разделами, вкладки — внутри одного |
| Путь до текущего экрана глубже второго уровня | [Крошки](./breadcrumbs.md) | У крошек нет полноты, только путь: список разделов ими не заменить |
| Список, разбитый на страницы с адресами `?page=3` | [Пейджер](./pagination.md) | В бесконечной ленте номер страницы ничего не значит |
| Процесс с известным числом этапов, который ведёт человек | [Шаги мастера](./steps.md) | У вкладок нет порядка и незавершённости |
| Инструменты, действующие на содержимое **этой** панели | [Тулбар](./toolbar.md) | Действия над экраном целиком — в [шапке экрана](../../layout/page-header.md) |

## Когда ни один не подходит

| Что нужно | Возьмите | Почему не отсюда |
|---|---|---|
| Выбор одного значения из равных | [сегментированный контрол](../actions/segmented.md) | Это ввод, а не переход: значение отправляется с формой |
| Раскрывающаяся иерархия объектов | [дерево](../../agent/tree.md) | У пункта навигации нет уровня и раскрытия |
| Список действий по клику | [меню](../overlays/menu.md) | Навигация ведёт на адрес, меню запускает действие |
| Поток без конца | догрузка по прокрутке | Номер страницы в бесконечной ленте не значит ничего |
| Живая лента событий | [лог](../../agent/log.md) | В нём читают хвост, а не страницу №7 |
| Работа машины с раскрывающимся телом | [шаг прогона](../../agent/step.md) | У него есть вывод, у шага мастера только подпись |
| Доля выполненного числом | [мера](../charts/meter.md) | Полоса без имён этапов |
| Название экрана | [шапка экрана](../../layout/page-header.md) | Крошки не заменяют заголовок |

## Общее для всех шести

**Переход — это `<a>`.** Кнопка, ведущая на адрес, ломает средний клик,
«открыть в новой вкладке» и копирование ссылки. Единственное исключение —
настоящие вкладки с `role="tablist"`, у которых своего адреса нет.

**Текущее положение объявляется атрибутом, а не классом.** `aria-current="page"`
у ссылки, `aria-selected` у настоящей вкладки. Класс красит, но не
произносится.

**Порядок обхода совпадает с порядком в разметке.** Визуальная перестановка
колонок без перестановки узлов ломает `Tab` — это относится ко всем шести
одинаково.
