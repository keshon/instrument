Состояние объекта, названное словом из **фиксированного словаря кита**. Пять
значений, и добавить шестое случайно нельзя.

```html preview
<span class="inst-badge"><span class="inst-dot"></span>в очереди</span>
<span class="inst-badge" data-tone="running"><span class="inst-dot"></span>идёт</span>
<span class="inst-badge" data-tone="ok"><span class="inst-dot"></span>готово</span>
<span class="inst-badge" data-tone="warn"><span class="inst-dot"></span>с замечаниями</span>
<span class="inst-badge" data-tone="error"><span class="inst-dot"></span>упало</span>
```

## Когда использовать

| Используйте | Возьмите другое |
|---|---|
| Состояние из перечислимого набора: идёт, готово, упало | **Произвольный текст, заведённый пользователем** — [тег](./tag.md). Бейдж — словарь кита, тег — слова пользователя, и снять его можно |
| Короткая неизменяемая метка объекта | **Счётчик рядом с пунктом навигации** — `inst-nav-count` |
| Статус строки таблицы или карточки | **Сообщение с объяснением** — [сноска или баннер](../feedback/banner.md): у бейджа нет места для предложения |

## Тон

Тон — это `data-tone`, **один словарь на весь кит**. Тот же атрибут с теми же
значениями работает на сноске, баннере, точке и строке лога.

| Тон | Значит |
|---|---|
| без атрибута | Нейтральное, ещё не начавшееся |
| `data-tone="neutral"` | Явно нейтральное. Оно же исполняет роль info — синий в этом ките занят акцентом |
| `data-tone="running"` | Идёт сейчас. Точка внутри **пульсирует** |
| `data-tone="ok"` | Успешно завершено |
| `data-tone="warn"` | Завершено с замечаниями |
| `data-tone="error"` | Упало |

Бейдж читает `--tone-ink` и `--tone-bg` и больше ничего о тоне не знает. Точка
внутри наследует тон от бейджа, поэтому атрибут ставится **один раз на группу**,
а не дублируется в разметке.

## С точкой и без

```html preview
<span class="inst-badge" data-tone="ok"><span class="inst-dot"></span>готово</span>
<span class="inst-badge" data-tone="ok">готово</span>
<span class="inst-badge">terrain_chunk_04</span>
```

Точка — не украшение. Она носитель второго признака: **цвет не имеет права
быть единственным носителем состояния**, поэтому статус ходит с точкой *и*
словом. Бейдж без точки применяется там, где он не статус, а метка объекта.

## Композиции

### Счётчик в навигации

```html
<a class="inst-nav-item" href="#">Очередь
  <span class="inst-badge inst-nav-count">7</span></a>
```

### В шапке панели

```html
<div class="inst-panel-header">
  <span class="inst-panel-title">Прогон</span>
  <span class="inst-badge" data-tone="running"><span class="inst-dot"></span>идёт</span>
</div>
```

## Справочник

### Классы

| Класс | Работа |
|---|---|
| `inst-badge` | Базовый |
| `inst-dot` | Точка состояния внутри. Наследует тон от бейджа |
| `inst-nav-count` | Модификатор положения для счётчика в навигации |

### Атрибуты

| Атрибут | Словарь |
|---|---|
| `data-tone` | `neutral` `running` `ok` `warn` `error`. Закрыт |

### Токены

`--control-h-xs` · `--radius-xs` · `--text-2xs` · `--weight-medium` ·
`--space-2` · `--space-3` · `--size-dot` · `--tone-ink` · `--tone-bg`

Если строите на тоне свой компонент: у тона **два** передних плана, и брать
надо тот, что по работе. `--tone-ink` — для текста, порог 4.5:1.
`--tone-mark` — для метки без подписи (точка, каретка, заливка меры), порог
3:1, но ещё и против дорожки. У статусов они совпадают, у акцента расходятся.

## Доступность

| | |
|---|---|
| Цвет не единственный носитель | Статус несёт точку **и** слово. Читатель, не различающий тон, читает подпись |
| Контраст | Подпись каждого тона проверена на 4.5:1 против собственного тонированного фона в четырёх темах. Ради этого у тона есть отдельный шаг рампы под текст: шаг заливки не вытягивает 4.5:1 на самом себе |
| Уменьшенное движение | Пульсация точки `running` **замедляется, а не гаснет**: кит, вся работа которого — показывать занятость машины, обязан показывать её всегда |
| Режим принудительных цветов | Точка переживает сброс (`forced-color-adjust: none`), потому что несёт значение |
| Кегль | `--text-2xs` — 11px, пол кита. Ниже не опускаемся |
