# instrument

CSS-библиотека для интерфейсов, которые показывают человеку работу машины:
очереди задач, прогоны, логи, инспекторы, состояния и неопределённость.

**[instrument.keshon.ru](https://instrument.keshon.ru)** — документация с
живыми примерами: каждый можно потрогать на странице, в любом из 360 сочетаний —
шесть тем, четыре акцента, пять масштабов, три плотности.

Библиотека рассчитана на дашборды, админки и агентские инструменты: экраны, где
главное — данные, и где человек наблюдает за работой машины. Визуальные эффекты
ограничены: нет градиентов, свечений и теней на карточках, из начертаний — только
обычное и медиум, заголовки капсом запрещены правилом. Для лендингов, магазинов
и контентных сайтов это не подходит.

## Установка

Сборки и зависимостей нет. Один файл — 106 КБ, 17 КБ в gzip: токены, шесть тем,
пять масштабов, три плотности, все компоненты.

```bash
npm i @keshon/instrument
```

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@keshon/instrument@0.6.2/dist/instrument.min.css">
```

Версию в адресе указывайте точно: `@latest` кэшируется на неделю и может
обновиться в произвольный момент.

Иконки требуют спрайта в самом документе: `<use href="#i-close">` подчиняется
правилу одного источника, и ссылка на внешний файл не отрисуется — без ошибки в
консоли. Содержимое `assets/sprite.svg` (17 КБ, 99 символов) вставляется первым
элементом `<body>`.

Полная процедура, включая целую страницу для копирования, — в
[установке](docs/start/install.md).

## Пример

```html
<div role="listbox" aria-label="Очередь агентов">
  <div class="inst-task" role="option" data-state="running"
       aria-selected="true" tabindex="0">
    <span class="inst-task-gutter"><span class="inst-dot"></span></span>
    <span class="inst-task-main">
      <span class="inst-task-title inst-u-truncate">Разбор карты высот</span>
      <span class="inst-task-sub">terrain/heightmap.ts · 4 файла</span>
    </span>
    <span class="inst-task-meta">2,1 с</span>
  </div>
</div>
```

`role`, `aria-*` и `data-state` — часть разметки компонента, а не дополнение к
ней. `data-state` красит строку, `aria-selected` подсвечивает выбор; без
`role="listbox"` и `role="option"` первое невалидно, второе не озвучится.
Обязательная разметка каждого компонента перечислена в
[принципах дизайна](docs/about/design-principles.md#разметочный-контракт).

Собранный экран, из которого видно, как компоненты стыкуются, — в
[консоли прогонов](docs/blocks/console.md).

## Что внутри

В поставке два файла: `instrument.min.css` и `instrument.js`. Собраны они из
исходников в `src/`:

| Файл в `src/` | Что |
|---|---|
| `tokens.css` | рампы, семантика, роли, шесть тем, четыре акцента, пять масштабов, три плотности |
| `base.css` | сброс, умолчания элементов, фокус, скроллбары, проза |
| `layout.css` | оболочка, контейнер, поток, шапка экрана, навигация |
| `components.css` | кнопки, поверхности, таблица, состояния |
| `forms.css` | поля, валидация, раскладка формы |
| `data.css` | аватар, тег, лента, легенда, спарклайн, кольцо, календарь |
| `overlay.css` | поповер, меню, тултип, модалка, шторка |
| `agent.css` | агентный слой и режим принудительных цветов |
| `motion.css` | `prefers-reduced-motion` |
| `print.css` | `@media print` |
| `kit.js` | поведение клавиатуры, опционально — в поставке это `instrument.js` |

Подключать по одному не нужно: `kit.css` объявляет порядок слоёв, и он же
попадает в собранный `instrument.min.css`.

```
kit.tokens → kit.base → kit.layout → kit.components → kit.overlay
  → kit.agent → kit.motion → kit.print
```

Стили приложения лежат вне слоёв и всегда выигрывают — без `!important`.
Подробнее — в [токенах](docs/foundations/tokens.md#порядок-слоёв).

## Возможности

**Темы, акцент и плотность — атрибуты разметки.** Работают на любом поддереве,
не только на документе.

```html
<html data-theme="dark">            <!-- шесть тем; без атрибута — по настройке ОС -->
<html data-accent="clay">           <!-- петроль (умолчание) · graphite · indigo · clay -->
<section data-density="compact">    <!-- compact · comfortable -->
```

Четыре оси не пересекаются: 6 тем × 4 акцента × 5 масштабов × 3 плотности.
Масштаб и плотность — обе атрибут контейнера, а не вариант компонента, и
различает их кегль: масштаб двигает его вместе с геометрией, плотность не
трогает вовсе. Подробнее — в [цвете](docs/foundations/colors.md),
[масштабе](docs/foundations/scale.md) и [плотности](docs/foundations/density.md).

**Доступность.** Контраст пар токенов проверяется машиной — 2208 проверок в
шести темах и четырёх акцентах; цели нажатия — против WCAG 2.2 AA в трёх
плотностях. Поддержаны `prefers-reduced-motion`, `forced-colors` и
`@media print`. Отдельная [проверка по пикселям](docs/about/audit.md)
запускается в браузере на вашем приложении.

**Клавиатура.** Стрелки, `Home`/`End` и бегущий `tabindex` для списка, дерева,
меню, радиогруппы и вкладок выполняет отдельный файл:

```html
<script type="module" src="dist/instrument.js"></script>
```

Он опционален и ставит только атрибуты, объявленные в разметочном контракте.
Без него работает всё, что не требует клавиатуры. Подробнее — в
[поведении](docs/foundations/behavior.md).

## Требования

Chrome 123+ · Safari 17.5+ · Firefox 120+

По `light-dark()`, `oklch()`, каскадным слоям, вложенности, `:has()` и единице
`lh`. Полифилов нет.
